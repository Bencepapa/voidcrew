## Goal
The per-tool panels leave the tool bar and become ONE Inspector in the right column ("properties"): it shows the selected element's fields, grouped, and the Map settings when nothing is selected. Numbers become `NumberField`s. Behaviour stays the same: every field does what it did.
1. New `src/editor/Inspector.tsx` (+ small per-kind files under `src/editor/inspector/`, e.g. `PropFields.tsx`, `LightFields.tsx`, `ActorFields.tsx`, `DoorFields.tsx`, `DecalFields.tsx`, `ItemFields.tsx`, `SmokeFields.tsx`, `ExitFields.tsx`, `ChanceWallFields.tsx`, `MapFields.tsx`, shared bits in `inspector/parts.tsx`). Move the panel code out of `EditorBar.tsx` (do not rewrite what a panel does, move it and tidy it), keep the exported `*Info` types where App imports them (re-export from EditorBar or move them and fix the imports in App.tsx).
2. Layout of the Inspector: a header (what it is: kind icon/letter, type name, cell `x,y`, the thumbnail where the asset has one), collapsible sections (native `<details>`) per kind: **Transform** (position/offset, rotation, height/elevation, scale), **Look** (texture, colour, intensity, range, size...), **Logic** (chance, links `with`/`without`, id), **Advanced** (rarely used: NPC wake rules, door lock/hack/code/says, smoke blow, light effect). Remember which sections are open per kind (localStorage, try/catch). Delete/Done buttons at the bottom of the header or footer as today.
3. Use `NumberField` for every number: slider mode (`min`/`max`/`slider`) for bounded values (chance 0-1 shown as percent, intensity, range, amount, size), plain drag-number for open ones (height, elevation, turn/rotation in degrees with a sensible step, scale, door Place offset). Each with `defaultValue` (double click on the label resets), unit (`°`, `%`, `x`), digits; `onChange` live and `onCommit` at the end of a drag. IMPORTANT: a drag must be ONE undo step: look at how the current sliders pass a merge key to `applyEdit` (see `App.tsx`: `applyEdit(..., merge)`), keep exactly that behaviour (the callbacks the panels call already merge; just make sure a drag does not create dozens of undo steps and that the 3D view updates live without a full rebuild, as the sliders did). If NumberField needs small improvements for this (touch support, `onCommit` semantics, step by Shift/Ctrl, a `labelWidth`), you may edit `NumberField.tsx`.
4. The tool bar keeps only tools and the tool-specific palettes (what to place: the texture palette, NPC type choice, prop/decal/item/light/smoke type pickers); per-element fields live in the Inspector. The Inspector also opens for a selected element even if another tool is active (App has `selectedProp`, `selectedDecal`, `selectedItem`, `selectedLight`, `selectedActor`, `selectedSmoke`, `selectedExit`, `selectedChanceWall`, `selectedDoor`; the full "one selection state" refactor is step 3, NOT yours: in App.tsx just derive one `inspected` value from these (the most recently selected one wins; clearing one clears it) and pass it to `<Inspector>`). Keep the App.tsx edit small and clearly commented.
5. Map settings (nothing selected): the Map tool's current panel content (map dropdown, resize edges, New map / Save as, baked light density, relief, accent, weather via the existing `WeatherFields`) moves into `MapFields.tsx`; the Debug panel's blocks stay where they are (Debug), do not touch `DebugPanel.tsx`.
6. i18n: new area files `src/i18n/en/inspector.ts` and `src/i18n/hu/inspector.ts`; register them in `src/i18n/index.ts` (one import + one spread each, the only edit to that file). Reuse existing `editorBar.*` keys where the same text already exists (do not duplicate; Hungarian glossary in `i18n-brief.md`).
7. Styling: the editor has its own style, not the game's: dark neutral panels (`bg-neutral-900/950`, `border-neutral-700`, small type 11px, tight padding), amber only for the active/selected state. No game-UI ornament. It must read well in BOTH worlds (the sci-fi decks are grey/green, the fantasy ones brown/orange) and in both languages (Hungarian text is ~25% longer: no fixed-width labels that break).
