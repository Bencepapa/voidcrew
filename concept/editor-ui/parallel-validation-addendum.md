# Addendum to parallel-minimap-brief.md (second pass, same clone and branch)

You built the minimap parts and `src/editor/validate.ts` on `feature/minimap-validation` (read your own commits and the brief again first). The owner asks the problems list to gather two kinds of problem explicitly. Do them, commit, report.

## 1. Things left in walls ("falban maradt")
A dedicated check group `inWall` (codes like `inWall.prop`, `inWall.item`, `inWall.actor`, `inWall.light`, `inWall.smoke`, `inWall.exit`, `inWall.ladder`, `inWall.bridge`, `inWall.door`, `inWall.chance`, `inWall.decal`, `inWall.restricted`, `inWall.start`): for EVERY kind of placed thing in the map data (props, actors incl. their patrol cells, items, lights incl. ceiling lamps, smoke emitters, exits, ladders, bridges, doors, chance walls, restricted cells, decals - a decal on a wall FACE is fine: report only decals whose host surface cell is solid in a way that hides them, e.g. a floor/ceiling decal inside a wall cell, or a wall decal whose open neighbour cell does not exist; the start cell), report one problem per thing whose cell is a wall (use the real cell data of the parsed map; for free-standing things also check their actual position, not only their cell, e.g. a prop whose reach crosses into a wall cell: warn only if clearly inside, not for a prop hugging a wall). Each problem carries the `cell`, the kind and its index so the list can jump to it; severity error for gameplay objects (actors, doors, ladders, bridges, exits, start, items), warning for decoration (props, decals, smoke, lights). Messages in English + Hungarian (e.g. "Prop #3 (crate1) is inside a wall at 8,4" / "A(z) 3. tárgy (crate1) falban van: 8,4").
Also provide a pure helper `removeInWall(file: MapFile): MapFile` in `src/editor/mapEdits.ts`-style (put it in `src/editor/validate.ts`, do NOT edit mapEdits.ts) that returns a copy of the map file with those things removed, for a "Remove them" button on the problems panel (`ProblemsPanel` gets an optional `onFix?: (code: string) => void` prop; the wiring in App.tsx is ours later).

## 2. Duplicates in one position ("dupla elemek egy pozícióban")
A check group `duplicate`: two or more things of the SAME kind at the same position (same cell AND the same fine position/anchor/offset within a small tolerance, e.g. props with the same `prop`, `at`, `offset`, `elevation`, `rotation`; items with the same item and offset; lights at the same cell and pos (or two ceiling lamps in one cell); smoke emitters at the same pos; NPCs in the same cell; exits / restricted / chance walls / ladders (same cell and wall) / bridges / doors listed twice; decals on the same surface with the same decal and px/py). Also "stacked" things of different kinds that cannot both be there (two NPCs, an NPC inside a closed door cell...) only if clearly a mistake. One problem per duplicate group (not per member), listing the indexes; severity warning (error for NPCs, doors, exits, ladders, bridges). Provide `removeDuplicates(file: MapFile): MapFile` (keeps the first of each group) in `validate.ts` for a "Remove duplicates" button (`onFix("duplicate")`).
